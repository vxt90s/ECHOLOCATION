# ECHOLOCATION

A browser-based horror and action game experience featuring two different game modes.

## 🎮 About the Project

**ECHOLOCATION** is a browser game built with HTML, CSS, and JavaScript, using Three.js for 3D graphics.

It currently features two playable experiences:

### Game 01 — Sound of Survival
- First-person survival horror.
- Navigate through a dark maze.
- Use sonar pulses to reveal your surroundings.
- Collect discs and find the beacon to escape.

### Game 02 — Demon Arena
- Third-person pixel-art-inspired action gameplay.
- Fight monsters using a sword.
- Face different enemies, including Medusas and eye-bats.
- Survive five waves and face the final dragon.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Three.js

## 💻 Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/vxt.90s/echolocation.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.

An internet connection is required to load the Three.js library from its CDN.
